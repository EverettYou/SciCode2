# Agent workflow

**Summary**: Agents work through focused, reusable skills; read compiled knowledge before raw sources; write durable artifacts at the owning layer; and use the talk when scientific judgment or user authority is required.

**Sources**: [Skill catalog](../../skills/README.md); [`auto-research`](../../skills/auto-research/SKILL.md); [talk contract](../../talk/README.md)

**Last updated**: 2026-08-23

Paper acquisition, assessment, benchmark creation, wiki operations, research coordination, and human consultation are separate workflows with explicit write boundaries. The coordinator delegates to focused skills rather than embedding their detailed procedures in project prose [Skills catalog](../../skills/README.md).

For research, an agent begins with the relevant wiki index and thesis, follows linked pages, and returns to raw sources only for verification or uncovered evidence. Completed experiments update reports before they update compiled knowledge. Scientific conflicts are preserved and routed for judgment rather than silently merged.

User–agent coordination is asynchronous. Agents continue independent work when possible, but decisions that change scope, scientific interpretation, or authority are placed in the project talk with durable context and links [Research talk README](../../talk/README.md).

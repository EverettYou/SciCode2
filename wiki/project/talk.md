# Research talk

**Summary**: The talk is the persistent, project-wide supervision forum linking user and agent decisions to papers, one or several benchmarks, excerpts, and durable project artifacts.

**Sources**: [Talk contract](../../talk/README.md); [`consult-human`](../../skills/consult-human/SKILL.md)

**Last updated**: 2026-08-23

Every conversation is a Markdown thread under `talk/threads/`. Free-form context may contain paper IDs, benchmark IDs, excerpts, links, or instructions; detected benchmark IDs provide routing without forcing the user to classify the conversation in advance [Research talk README](../../talk/README.md).

The final active author determines who should reply next. Agents report resolutions, while only the user closes or reopens threads. The talk is operational history and supervision, not scientific evidence; decisions that affect scientific claims must still be reflected in the appropriate assessment, problem, lab report, or wiki.

The dashboard exposes the global forum and the relevant filtered subset on benchmark pages.

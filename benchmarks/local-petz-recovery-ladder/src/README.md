# Stable source

This directory contains stable, reusable implementation distilled from supported lab work. Exploratory scripts remain in labs.

Planned promotion boundary:

- dense Petz maps used only for overlap validation;
- commuting Petz or Bayesian reverse-channel construction;
- stabilizer or Pauli-error-class geometry and local restrictions;
- CMI, Petz-gap, recovery-length, and logical-channel metrics;
- tensor-network or Monte Carlo estimators with uncertainty diagnostics;
- schema-validated configurations and reproducible result records.

No implementation has yet crossed this boundary.

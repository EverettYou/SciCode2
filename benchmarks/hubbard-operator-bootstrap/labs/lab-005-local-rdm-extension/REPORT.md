# Local density positivity beyond global cubic constraints

## Motivation

Test whether inexpensive local density positivity detects violations in the global candidate moments.

## Design

Exact Fourier matching to four-site density matrices and discriminating compatibility screens before a joint energy optimization.

## Findings

### Motivation and design

Global P/Q/G/T1/T2prime conditions may allow two-particle marginals that fail to extend to a positive four-site density matrix. This lab tests that hypothesis before paying for a larger joint SDP. A four-site local density matrix is PSD in 25 spin-number blocks, with all local one- and two-particle density entries coupled to global moment coordinates by exact Fourier maps.

### Completed evidence

The exact Fourier maps passed two independent physical cases for all 198 entries: a fixed-number maximally mixed state with hypergeometric local density probabilities, and a closed-shell Slater state checked using Wick determinants. The former uses Python Fraction arithmetic; the latter uses exactly representable Gaussian-integer/dyadic coefficients. Both have exactly zero discrepancy. See [physical-map-checks.json](results/physical-map-checks.json).

The full T2prime symmetry-reduced candidate admitted numerical extensions on all tested shapes. Maximum uniform moment mismatches were 4.68e-10 (plaquette, 17.51 s), 4.69e-10 (four-site row, 10.06 s), 1.21e-10 (three-neighbor star, 9.93 s), and 4.42e-11 (zigzag, 4.81 s). Measured process peaks were 207–218 MB for the latter three; the first run did not record peak RSS. The compact two-site T2prime candidate also admitted a plaquette extension with mismatch 1.16e-10 in 4.26 s, 218 MB. All used 10 Clarabel iterations with status optimal_inaccurate. See the shape-specific JSON files under [results](results/).

These are numerical compatibility observations, not exact feasibility theorems. The candidate itself is a numerical SDP moment vector; no energy bound is deduced from a local primal fit.

### Search decision and interpretation

Prune the immediate joint SDP branch because no local violation beyond numerical residuals is observed. This does not prove four-site positivity redundant for every moment vector. The implementation remains in this lab rather than the stable core.

Local density positivity can be generated by the 256 matrix-unit operators |vacuum><alpha| on the four-site Fock space, together with all 16 translations. Their Gram enforces local density PSD; spin number averaging yields 25 blocks (maximum 36). This space includes higher fermionic degree than global cubic constraints. The small cones hide 2578 local real variables and 198 matching equations; full joint cost was not incurred after these discriminating feasibility experiments.

# Text-only formulation audit: revision 0.4 finite-forward general-H

**Recommendation: pass-to-testing, with useful-regime feasibility and difficulty uncertainty.** This is an early editorial judgment under the current SciCode2 creation workflow. It is not human expert approval, empirical model difficulty evidence, formal calibration, or organizer acceptance.

The question is self-contained and grounded in public references. It fixes the sparse-H decoding target, the physical target graph and coefficient constraints, an ideal finite closed-system anneal, and an original-error success event. It leaves representation, embedding selection, the efficient criterion, proof strategy, and useful regime open. A solution needs substantive work connecting a cheap decision rule to finite-time performance and checking when that connection is informative. It allows conditional and negative results, so it does not demand a universal winner or large-device simulation.

The principal feasibility risk is the combination of general-H compilation, useful finite-time theory, independent physical anchors, and comparisons on reserved instances. The task explicitly allows inconclusive regimes and requires a trial-specific resource and input manifest before scored testing. Whether a fair, useful cohort fits the available budget remains to be established in exploratory testing.

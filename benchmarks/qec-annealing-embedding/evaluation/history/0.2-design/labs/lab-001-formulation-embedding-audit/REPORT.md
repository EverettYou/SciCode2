# Formulation and embedding audit

## Motivation

Determine whether the cost of a proposed decoding representation survives faithful quadratic reduction and routing onto a declared Advantage2 graph. The current [synthesis](../../wiki/thesis.md) supports this as the first decisive comparison, but supplies no experiment result.

## Design

After further user authorization, use exact small CSS instances, a boundary-correct toric family and a non-toric matrix-defined CSS family. Let the researcher choose candidate encodings and embedding methods. Compare source graphs, correctness, resource costs, hardware scaling and reuse under explicit budgets. Use an automatic Ocean/minorminer reference and independent mathematical checks. Log unavailable target-device information and conditional claims. A failed or unfavorable construction is a valid result if it narrows the question reproducibly.

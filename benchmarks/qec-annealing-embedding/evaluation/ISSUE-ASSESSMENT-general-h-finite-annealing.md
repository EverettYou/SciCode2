## Why this is a substantive refinement

The central unresolved issue is whether a fast embedding/programming decision genuinely helps original-error decoding under a finite forward anneal. Smaller mappings, stronger static penalties and terminal-equilibrium certificates can be mathematically valid while failing to establish that outcome. The new issue fixes the physical model and readout, leaving the scientific approach open. This follows a real research gap rather than adding arbitrary complexity to manufacture failure.

It preserves the user's general sparse-H goal. It does not require CSS form, one code family or logical-sector enumeration. The separate candidate-v0.5 logical-decision problem remains an alternative formulation; this issue instead retains the original minimum-cost-correction target explicitly.

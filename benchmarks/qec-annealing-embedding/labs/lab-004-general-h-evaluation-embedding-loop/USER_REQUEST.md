# User-authorized research round

那下一轮就重点解决这个闭环：针对一般稀疏 H，发展在常规实例上有用、计算成本低的理论评价准则，并用它指导更紧凑的 embedding。让 agent 自主选择方法，不要再只靠特殊 toy case 或某一种 code 的结构来完成任务。

English scope: develop an inexpensive theoretically justified embedding evaluation useful on ordinary structurally diverse sparse H, and close the loop by using it to guide more compact embeddings. Methods are autonomous. Special toy examples or a code-specific geometry cannot be the sole success evidence.

# Stable source

This directory is reserved for reusable implementation distilled from completed lab evidence. Exploratory code remains node-local.

Planned promotion boundary:

- canonical MPS environments and weak-measurement sampling;
- pinned Quimb adapters for parametrized `Circuit`, `CircuitMPS`, MPS gate splitting, and automatic-differentiation backends;
- differentiable Suzuki--Trotter feedback with gauge, Trotter, and truncation diagnostics;
- translation-equivariant record encoders, finite-range Hermitian controllers, and brick-wall local-gate controllers;
- exact-state parity backends and companion-convention adapters;
- reduced-state, trajectory-distribution, entanglement, and resource metrics;
- reproducible configurations and result schemas.

No implementation has yet crossed this boundary.

New author draft: [certified quantum-information recoverability](recoverability/README.md).
It includes a solver-facing candidate, evaluation contract, evidence inventory and
blind-difficulty plan. Exact anchors and nontrivial N=2,4 reference grids are executable; an N=6 pilot
also passes independent verification. Large-instance release and AI difficulty remain pending. It does not replace the historical task below.

The global wiki ingests those folders once. This benchmark must cite the resulting global pages rather than copying source material or re-ingesting it locally.
